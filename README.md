# Bora de quê?

Aplicativo que ajuda a escolher uma atividade para o tempo livre, de acordo com o tempo disponível, o orçamento, o local e a companhia.

## Funcionalidades

- Sugestões de atividades com filtros, busca e categorias.
- Sorteio entre as atividades que combinam com as escolhas do usuário.
- Detalhes com duração, custo estimado, materiais e passo a passo.
- Favoritos e histórico de atividades realizadas.
- Filtros, favoritos e histórico disponíveis enquanto o app estiver aberto. Esses dados são perdidos ao fechar ou recarregar o aplicativo.

## Tecnologias

React Native, Expo SDK 57, TypeScript, React Navigation e Context API.

## Como executar

Use Node.js 22 e npm no computador, além do Expo Go compatível com o SDK 57 no celular.

Na pasta do projeto, execute:

```sh
npm ci
npm start
```

Conecte o computador e o celular à mesma rede Wi-Fi. No Android, leia o QR code pelo Expo Go. No iPhone, use a câmera e abra o link no Expo Go.

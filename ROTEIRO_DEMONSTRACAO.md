# Roteiro de demonstração — Bora de quê?

Duração aproximada: 3 minutos. Abra o app no Expo Go antes de gravar. Use fonte e zoom normais; habilite não perturbe. Deixe o histórico e os favoritos com poucos registros para facilitar a apresentação.

| Tempo | Ação na tela | Sugestão de fala |
| --- | --- | --- |
| 0:00–0:20 | Mostrar o início e rolar devagar | “Este é o Bora de quê?, um aplicativo para escolher o que fazer no tempo livre. A proposta é encontrar uma atividade a partir do tempo, orçamento, local e companhia.” |
| 0:20–0:40 | Selecionar até 30 minutos, grátis, tanto faz para local e companhia | “Os filtros são cumulativos. Quero uma ideia rápida e gratuita. O aplicativo usa um catálogo local com 28 opções e não depende de uma API.” |
| 0:40–1:00 | Tocar Encontrar ideias; mostrar quantidade, busca e categoria | “Aqui estão apenas as atividades compatíveis. A busca ignora acentos e letras maiúsculas. Também posso escolher uma categoria ou voltar e ajustar os filtros.” |
| 1:00–1:25 | Abrir uma atividade, mostrar descrição, materiais e passos; salvar favorito | “Os detalhes apresentam uma ilustração local, duração, custo estimado por pessoa e um passo a passo. O coração guarda a ideia para outro momento.” |
| 1:25–1:45 | Voltar; limpar busca/categoria caso necessário; Sortear uma ideia | “O sorteio usa os resultados que estou vendo. Ele respeita minhas escolhas e evita repetir imediatamente a última sugestão quando há outras opções.” |
| 1:45–2:05 | Tocar Já fiz essa! e Ver meu histórico | “Agora registro que realizei essa atividade. A data e a hora aparecem no histórico. Posso registrar a mesma atividade em outro momento.” |
| 2:05–2:25 | Mostrar favoritos; voltar ao histórico; abrir exclusão e cancelar | “Os favoritos continuam disponíveis independentemente dos filtros. No histórico, a exclusão pede confirmação e remove apenas o registro escolhido.” |
| 2:25–2:55 | Mostrar brevemente a estrutura no editor ou narrar com a interface aberta | “Usei componentes funcionais. Props levam os dados para os cartões; State controla busca e seleção. As listas usam FlatList. O React Navigation combina abas inferiores com uma Stack para os detalhes. Context API compartilha o estado e AsyncStorage mantém favoritos, histórico e filtros ao reabrir.” |
| 2:55–3:00 | Voltar ao início | “Seu tempo livre merece uma boa ideia. Esse é o Bora de quê?” |

## Preparação e entrega

1. Execute `npm start` e abra no Expo Go com o celular na mesma rede do computador.
2. Teste os fluxos do checklist do README antes de gravar.
3. Se houver tempo no vídeo, feche e reabra o projeto para demonstrar a persistência.
4. Explique que os valores são estimativas e que os materiais existentes tornam algumas ideias gratuitas.
5. Grave com a ferramenta de captura de tela do próprio celular. Revise áudio, legibilidade e duração.
6. Publique o vídeo e o repositório apenas quando decidir fazê-lo, seguindo as orientações da disciplina.
